# 호환성 안내

<ItemImage id="extendedmolecularassembler:extended_crafting_pattern" scale="4" />

Extended Molecular Assembler는 대형 작업대 조합법과 AE2 자동 조합 연동에 중점을 둡니다.

## 대형 조합법 모드

사용할 수 있는 조합법 제공자는 모드팩에 설치된 모드에 따라 달라집니다.

* Extended Crafting.
* Re:Avaritia.
* Avaritia Neo.

여러 조합법 제공자가 같은 입력과 일치하면 인코딩하기 전에 확장 패턴 인코딩 터미널의 조합법 순환 버튼으로 원하는 조합법을 선택하세요.

## ExtendedAE 매트릭스 경계

EMA 매트릭스 지원은 ExtendedAE 매트릭스에 연결되는 별도 하위 시스템입니다.

매트릭스가 공유하는 요소:

* 클러스터 형성 상태.
* 속도 코어 수.

매트릭스가 공유하지 않는 요소:

* 패턴 저장 슬롯.
* 확장 작업 수.
* EMA 작업 취소 상태.

확장 패턴 저장에는 EMA 패턴 코어 블록을, 확장 작업 실행에는 EMA 조합 코어 블록을 사용하세요.

## AdvancedAE 퀀텀 크래프터

확장 퀀텀 크래프터는 현재 개발 중입니다. 개발 및 크리에이티브 모드 테스트에는 사용할 수 있지만 서바이벌 모드에서의 조합법은 없습니다.

## 용량 참고

| 블록 | 용량 |
|---|---:|
| EMA 패턴 코어 | 패턴 36개 |
| EMA 패턴 코어 플러스 | 패턴 72개 |
| EMA 조합 코어 | 작업 8개 |
| EMA 조합 코어 플러스 | 작업 32개 |
