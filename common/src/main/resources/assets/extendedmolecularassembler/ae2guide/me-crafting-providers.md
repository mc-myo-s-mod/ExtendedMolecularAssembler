# ME Crafting Providers

<BlockImage id="extendedmolecularassembler:basic_me_crafting_provider" scale="5" />

ME Crafting Providers are Expert Mode gate blocks for Extended Molecular Assembler autocrafting.

When Expert Mode is enabled, an extended crafting job is accepted only if the same ME network contains an online provider for the exact encoded recipe table.

## Extended Crafting Providers

These providers unlock Extended Crafting table recipes by tier:

| Provider | Recipe table |
|---|---|
| <ItemLink id="extendedmolecularassembler:basic_me_crafting_provider" /> | Extended Crafting Basic Table |
| <ItemLink id="extendedmolecularassembler:advanced_me_crafting_provider" /> | Extended Crafting Advanced Table |
| <ItemLink id="extendedmolecularassembler:elite_me_crafting_provider" /> | Extended Crafting Elite Table |
| <ItemLink id="extendedmolecularassembler:ultimate_me_crafting_provider" /> | Extended Crafting Ultimate Table |

## Re:Avaritia Providers

<BlockImage id="extendedmolecularassembler:re_avaritia_sculk_me_crafting_provider" scale="5" />

These providers unlock Re:Avaritia table recipes by tier:

| Provider | Recipe table |
|---|---|
| <ItemLink id="extendedmolecularassembler:re_avaritia_sculk_me_crafting_provider" /> | Re:Avaritia Sculk Table |
| <ItemLink id="extendedmolecularassembler:re_avaritia_nether_me_crafting_provider" /> | Re:Avaritia Nether Table |
| <ItemLink id="extendedmolecularassembler:re_avaritia_end_me_crafting_provider" /> | Re:Avaritia End Table |
| <ItemLink id="extendedmolecularassembler:xtreme_me_crafting_provider" /> | Re:Avaritia Extreme Table and Avaritia Neo Extreme Table |

The Xtreme provider is shared by both Re:Avaritia Xtreme recipes and Avaritia Neo extreme crafting recipes.

## Placement and Network Rules

* The provider must be on the same ME network as the assembler or EMA Matrix executing the job.
* The provider must be online.
* Providers do not open a screen and do not need manual interaction after placement.
* Different recipe tables require their matching provider tier.

If an extended crafting job is rejected in Expert Mode, check the encoded table shown by the Extended Pattern Encoding Terminal and place the matching provider on the same ME network.
